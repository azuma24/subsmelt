# Convert batches

The Convert page uploads each selected subtitle exactly once to `POST /api/convert/batches`. The server writes the bounded upload to its persistent `CONFIG_DIR/convert-batches` directory (override with `CONVERT_BATCH_DIR`), returns a random unguessable batch ID, and processes files serially independently of the HTTP connection. The UI saves the latest ID in localStorage, polls `GET /api/convert/batches/:id` after reload, and retrieves completed outputs from `GET /api/convert/batches/:id/files/:index`. The existing synchronous `POST /api/convert` remains available for legacy clients. ZIP creation is on demand in the browser from retrieved outputs; no output bytes live in UI state between visits.

The store accepts at most 10 files of 1 MiB UTF-8 each, at most 10 MiB total and 20 retained batches. Converted outputs are capped at 1 MiB each. A worker isolates each file's failure; after a process restart, pending/working files are retried while completed files are not. A crash *during* a file can cause that file's LLM request to run again. Settings/connection changes between upload and execution affect translation because credentials are not copied into the job record.

Inputs are deleted after each attempt and output files plus status are deleted 24 hours after completion (unfinished jobs expire 24 hours after submission). Cleanup runs on startup and every minute; capacity does not evict live batches. The directory must be on persistent storage to survive a server/container restart; backups of this directory contain private subtitle text. Files and job directories are created with owner-only permissions; protect the parent volume too. Batch IDs act as bearer capabilities: anyone with the ID on the same API origin can view names/errors and download output. Do not share batch URLs or expose the self-hosted API publicly without authentication. A browser that clears localStorage loses its latest ID, though server cleanup still expires it. No historical listing is provided to avoid disclosing other users' subtitles.
